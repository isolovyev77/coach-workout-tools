# Инструкция для ИИ-ассистента

Этот репозиторий помогает тренерам переносить и составлять тренировки между
BTWB и Trenda. Когда тренер просит объяснить или установить его, сначала
прочитай `README.md`, затем `skills/populating-trenda-workouts/SKILL.md`.

## Что объяснить тренеру

- `btwb-pp-cli` читает тренировки и треки BTWB, а также может планировать
  тренировку на личный или разрешённый трек зала.
- `trenda-pp-cli` читает и изменяет только данные из аккаунта самого тренера
  в Trenda.
- `cap-pp-cli` читает программу CrossFit Affiliate Programming, библиотеку
  движений с ошибками и подсказками, бенчмарки и ресурсы. Только чтение.
- Навык помогает переносить тренировку, готовить разминку и перепроверять
  результат после записи.
- Репозиторий не содержит клиентов, паролей, cookies или готовых сессий.

## Безопасная установка

1. Определи систему и архитектуру: `uname -s` и `uname -m`.
2. Предложи архив со страницы Releases:
   - `darwin_amd64` - Mac Intel;
   - `darwin_arm64` - Mac Apple Silicon;
   - `linux_amd64` - обычный Linux на Intel/AMD;
   - `linux_arm64` - Linux на ARM.
3. После распаковки предложи запустить:

   ```bash
   ./scripts/verify-public-release.py
   ./scripts/install.sh --configure-path
   ```

   Готовый архив не требует Go. Node.js нужен для интерактивного входа в
   Trenda.
4. Проверь доступность команд в новом окне терминала:

   ```bash
   btwb-pp-cli --help
   trenda-pp-cli --help
   cap-pp-cli --help
   ```

## Авторизация и данные

- Используй интерактивный вход: `btwb-pp-cli auth login`,
  `trenda-pp-cli auth login` и `cap-pp-cli auth login`. Если команда
  программирования CAP вернула код 4, предложи тренеру войти самому и не
  пытайся добыть токен обходным путём. Команды библиотеки (`cap movement`,
  `cap benchmarks`, `cap resources`) работают и без токена - на вопрос про
  движение или бенчмарк отвечай ими, не требуя входа.
- Никогда не проси пароль, cookie или токен в чате и не записывай их в файлы
  репозитория.
- Перед изменением тренировки уточни клиента, дату и содержание, если они не
  заданы однозначно.
- После записи перечитай созданную тренировку и сообщи результат.

## Планирование в BTWB

- До записи всегда выполни `btwb-pp-cli wod tracks`: это единственный список
  треков, доступных для записи текущему аккаунту. Без прав администратора
  зала BTWB обычно показывает только личный трек.
- Сначала покажи безопасный предпросмотр через `btwb-pp-cli wod plan ...
  --dry-run`. Не добавляй `--yes`, пока тренер явно не подтвердит дату, трек
  и текст тренировки.
- После подтверждения разрешён единственный узкий вызов `btwb-pp-cli wod plan
  ... --yes`. Затем прочитай соответствующий день в BTWB и проверь результат.
- Не удаляй запланированную тренировку через `wod unplan`, если тренер не
  назвал конкретный идентификатор записи и не подтвердил удаление отдельно.

## Работа с CAP

- `cap-pp-cli` ничего не записывает: это опубликованные материалы CrossFit.
- Вопрос «как учить движение» или «что делать, если атлет заваливает колени»
  закрывается командой `cap-pp-cli cap movement <название>`: она возвращает
  типовые ошибки вместе с подсказками, которые их исправляют.
- Вопрос про конкретный бенчмарк или геройскую тренировку - `cap-pp-cli cap
  benchmarks <название>`; поиск идёт и по названию, и по тексту тренировки.
- Прежде чем предлагать перестановку дней недели, посчитай столкновение через
  `cap-pp-cli cap compare <дата> <дата>` и опирайся на общие паттерны, а не
  только на числа нагрузки.
- Не пересказывай содержание тренировок CAP в файлы репозитория: это материалы
  по подписке. В репозитории лежат только тестовые заглушки.

## Обновление

Для клона из Git используй `./scripts/update.sh`. Он прекращает работу при
локальных изменениях, проверяет пакет на персональные данные и сохраняет
локальные сессии тренера.
